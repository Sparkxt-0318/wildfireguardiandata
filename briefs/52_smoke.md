Definition (write it as docs/SMOKE_EDGE.md, two pages, usable by annotators and by code).

* The label is a measured opacity map: at each pixel and frame, how much the smoke dims and veils the camera's own smoke-free background. The background comes from the frames before ignition, corrected for lighting drift.
* An edge is a contour of that map at a stated opacity. The lowest named level is set by the camera's own noise in the pre-ignition frames, not by a chosen number. The continuous map is the label; any level can be cut from it.
* First smoke is found by tracing back from a later, confirmed frame to the earliest frame where a region above the noise level persists and connects forward to the confirmed plume.
* Each pixel also carries a vector of measured variables: opacity, colour shift, loss of background texture, motion speed, motion direction, attachment to a fixed source point, growth. Classes (smoke, cloud, haze or fog, dust, other) are rules on that vector, each written in one plain sentence. No trained model decides a class.
* State what is out of scope (moving cameras without registration, night frames if they fail).

Tests and gates.

* S1, known truth: composite smoke of known opacity over real smoke-free frames. Used for testing only, never for fitting. Opacity error and edge position error at each level.
* S2, placebo: on the 40 minutes before ignition, at most 1% of frames show any smoke region.
* S3: first-smoke time against the human offset in the file names; report the distribution and which way it differs.
* S4: place existing human masks and boxes on the opacity scale (which level each annotator effectively drew at) and report agreement.
* S5: identical output on a re-run; sensitivity to the background window.
