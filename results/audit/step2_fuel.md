## 3. Data problems and observations

1. **F1/F2 grading data held out entirely.** The release contains no field plots (no AIM plot coordinates or cell indices, no compatible-group sets, no agree/disagree flags, no 10 km block ids) and none of `results/fuel/sealed_M22.json`, `sealed_M16.json`, `dev_*.json`, `stretch_*.json`, `sealed_F3.json`, `sealed_opened.json`. The data card says plots "are used only for grading, not in these files". So both gates and every plot-based secondary number rest on unreleased tables. Internal arithmetic of the published counts is consistent: (103/117)/(179/1609) = 7.913; (41/48)/(125/1638) = 11.193; (47/64)/(112/1615) = 10.589; contradicted-and-agree = 117-103 = 14 = F2 numerator (dev 48-41 = 7, v1 64-47 = 17, also equal); Wilson upper 14/1515 = 1.545 %, 7/1743 = 0.827 %, 17/1743 = 1.556 %, 8/1546 = 1.018 %, all as published.
2. **Released sealed overlays are not the frozen-code outputs by hash.** All 20 sealed manifests carry code_hash `65aa806449f3...`, while the repo's `results/fuel/RULES_FROZEN.json` (not a release file) records code_hash `226b82c4bb1c...`; config_hash `3f8614b6...` is the same. FUEL_RESULTS line 47 and the data card disclose this (loader gained an optional `cutoff_year` argument). The F1/F2 that were graded were therefore computed on overlays that are not the ones released; whether the released verdict rasters are cell-for-cell identical to the graded ones cannot be checked from the release.
3. **cards.jsonl missing** from all 49 folders (protocol section 7 output contract); disclosed ("nocards", 100 MB with them).
4. All 49 folders: raster counts (verdict values 1-4, rule bits 0-12, suggestions) equal their `overlay.json` counts exactly; no nodata cells; every grid 2000 x 2000 at 30 m. In the fires, a few suggestion cells are not contradicted (309,909 suggestion cells vs 309,134 contradicted-with-suggestion); only the latter enter the stretch replacement, as stated.
5. The 29 fires include FL (3), TX (2), WA (2) and CA fires, outside the interior West of the gate areas; the stretch is labelled separately, so not a contradiction.
6. Stretch line 33: better 7 + worse 20 = 27, n = 28; the remaining fire (tie or missing) is not stated.
