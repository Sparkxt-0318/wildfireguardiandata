## How the rounds were done (stated plainly, for audit)
* **Wrong verdicts read.** Version 1 on dev: 17 contradicted cells whose plot agrees with the map (false alarms) were read one by one (tile, plot class, map class, rules fired; 15 were R1.9 - 10 of them the grass-class-under-shrub case R1.9a - one R1.1, one R1.7) and the 112 consistent cells whose plot disagrees were cross-tabulated by plot class x map group (57 shrub plots mapped GR, 26 grass plots mapped SH, 13 shrub plots mapped NB, 8 tree plots mapped GR). Layer values at those plots (NLCD class, WorldCover shares, TCC, canopy height) were tabulated against the disagreement rate to look for a rule with higher precision than the current ones (the check that showed canopy height carries no shrub signal in this region, and that relaxing the GR-under-NLCD-shrub rule would raise the false alarms from 17 to 31). Round 1 comes from that reading.
* **Rounds 2-12 were threshold probes, not new readings.** After round 1 I did not re-read individual wrong verdicts. Each later round took the per-rule precision table (plots hit, share that disagree) from the previous run, named the rule whose threshold looked too strict (or, round 9, a rule that rarely fires), moved that one threshold, and reran. Rounds 6-9, 11 and 12 show those probes mostly change nothing or add false alarms. Round 12 changed no result. So the loop is shallow after round 1: three kept relaxations (R1.1, R1.7, R1.9b) each add 1-3 contradicted plots.
* **One change per round** (round 9 moved two thresholds of one rule, R1.2, and says so). F1 = ratio of disagreement rates, F2 = false-alarm share among agreeing plots, both pooled over the 10 dev areas, point estimates; the acceptance test is the protocol's (F1 up, F2 not up, n_c >= 25). The per-round JSON (with code hash and per-rule table) is `results/fuel/dev_r<n>_M22.json`.
* **Order of events (git history).** protocol + amendment A1 -> code -> version 1 run on dev (`dev_v1`) -> rounds 1-12 -> commit "rules frozen" (`results/fuel/RULES_FROZEN.json`) -> sealed layers for the last tile finished downloading, and the missing 2021 LANDFIRE disturbance layer was fetched for the sealed tiles (data completion, rules untouched) -> sealed run (`results/fuel/sealed_opened.json` written once, before any sealed plot was loaded, with the code and config hashes equal to the frozen ones; the command refuses a second run). After the sealed run: amendment A2 and an optional `cutoff_year` loader argument for the 29-fire stretch (default off), the stretch itself, and the release overlays.
* The first round-12 run (S2 threshold) is the last run before the freeze; the frozen rules are the `r10` state (rounds 6, 7, 8, 9, 11, 12 reverted).
